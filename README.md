Minimal XP Bar - Gives Level, Current/Max (%) % Rested %.

    Bar and Text Separators are class colored.
    Bar turns purple when you have rested XP (similar as the default XP bar does)
    Hides away at Max Level.
    Options to center text and have it show on mouse over implemented with version (Must edit LUA file to use options).



Works in Retail & Classic & Forever.

Configuration Options:
Code:

-- === CONFIGURATION OPTIONS ===
local TEXT_CENTERED = false          -- Set to true to center the XP text
local TEXT_MOUSEOVER_ONLY = false    -- Set to true to only show text when mousing over the bar
